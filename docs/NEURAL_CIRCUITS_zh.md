# FlyBrain Snake 神经回路与多模态气味门控视觉追踪指南

> **系统架构与设计理念 (System Architecture & Framework)**：  
> **“本项目探索的是一套典型的『连接组在环感觉运动伺服系统（Connectome-in-the-Loop Sensorimotor System）』：**
> 
> 1. **全脑动力学层 / 下行意图层 (Whole-Brain Dynamics / Descending Intent Layer)**：由真实的 **MaleCNS v1.0 166.7k** 脉冲全脑模型承担（MaleCNS 数据集包含 1.25 亿突触，运行时稀疏阵约 2,558 万条），执行 4 步 LIF 动力学，作为多模态（嗅觉气味门控 + 视网膜注视追踪）的**非线性生物动力学滤波器**，自发输出下行运动意图（`DNa02` 差模）。每步开始时通过 `brain.v.fill(0)` 复位膜电位，清空跨步运动迟滞，无跨 tick 隐层记忆残留；  
> 2. **低级反射层 (VNC 功能类比的净空 FSM)**：功能类比昆虫**腹神经索（VNC）与外周反射弧**，以确定性有限状态机（FSM）监控网格局部净空：在正前方遭遇致命碰撞（`dist_front == 0`）时执行毫秒级避碰覆写（Reflex Override），在侧边贴身（`dist_left/right == 0`）时主动抑制撞向障碍侧的转向指令；  
> 3. **空间接口层 (Spatial Interface Layer)**：充当**虚拟复眼与触角**，将连续网格几何翻译为触角叶（`AL`）、视小叶（`LC10a`）与视网膜隐现（`LC4`/`LPLC2`）的神经外加电压刺激（`brain.stimulate()`）。”
>
> 这一分层控制架构契合真实昆虫的感觉运动控制分工：中央复合体（CX）仪表盘作为状态提取与可视化监视，闭环转向决策则完全由 `DNa02` 下行运动差模与外周净空 FSM 给出。全脑计算在 16.6 万个果蝇神经元与稀疏突触连线上执行 4 步 LIF 脉冲网络传递，下行转向差模无左右常值偏置，外周净空 FSM 守护生存边界。

## 1. 神经回路工作流与映射总览

```text
======================= 闭环感觉运动控制主干 =======================

【1. 空间接口层（虚拟复眼与触角）】
  左右触角外周浓度采样: c_L, c_R
  双侧化学浓度差: Δc = c_L − c_R ──► 触角叶投射神经元 PN (DM1/VA2/DM2)
  视网膜几何偏航角: θ_bearing     ──► 视小叶柱状神经元 LC10a
  近距障碍逼近 (净空 <= 1)        ──► 视网膜隐现神经元 LC4 / LPLC2

【2. 编码器侧气味敏化门控 (Odor-Gated Sensitization)】
  当前遭遇峰值气味浓度: c_max = max(c_L, c_R)
  动态视觉增益调控公式（类比生物气味门控视觉追踪）:
      visual_gain = base_gain × (1.0 + α · c_max / c_0)
      （α = 1.5, c_0 = 5.0, base_gain = 3.5；接近食物时视觉敏锐度提升至 3～4 倍）

【3. 纯几何视网膜通道（视小叶 LC10a 目标追踪）】
  目标偏左 (θ_bearing < −0.05): stim_vis_L = min(8, |θ_bearing| × visual_gain)
  目标偏右 (θ_bearing > +0.05): stim_vis_R = min(8, |θ_bearing| × visual_gain)
        └─► LC10a（小叶柱状神经元）──► 视前结节 (AOTU) ──► 驱动向心定位置换

【4. 全脑动力学滤波与下行运动解码（4 步 LIF 脉冲网络）】
  DNa02_L / DNa02_R（同侧转向驱动下行神经元，全脑各 1 个，共 1 对）
      输出信号：DNa02_L = V_L / 2.0,  DNa02_R = V_R / 2.0
      读出规则：diff = DNa02_L − DNa02_R
      意图判决：diff > 0.03 → TURN_LEFT；−diff > 0.03 → TURN_RIGHT（无左右常值偏置）
  DNa01_L / DNa01_R（走步前行下行神经元，全脑 1 对）
      双侧协同提供基础巡航推进（STRAIGHT）；ΔCₜ 作为时序靠近/远离遥测（▲ Closer / ▼ Further）

【5. 低级反射层：外周净空 FSM 避碰（VNC 功能类比）】
  前方开阔 (dist_front > 0)  ──► 采纳 DNa02 意向转向 / DNa01 直行
  贴身障碍 (dist_front == 0) ──► 触发毫秒级外周避碰覆写 (Reflex Override 转向)

=================== 神经遥测与状态监视 HUD (只读监控流) ===================
(提取自仿真运行过程，用于前端科学可视化与状态监视，不参与动作决策闭环)

  • E-PG 罗盘环  : 由当前朝向重建的 16 楔示意（非 E-PG 原生胞体读出）
  • Δ7 中间神经元: 原脑桥内侧向抑制，维持罗盘波包锐利与抗噪
  • PFL3 比较器  : 扇形体到外侧副叶（LAL）双侧航向差模平衡表
  • PAM 多巴胺簇 : 进食瞬间触发琥珀金色奖赏神经烟花（35 帧衰减）
  • 3D 全脑呈现  : WebGL 按事件点亮解剖区位（视小叶火花、全脑光流与 VNC 轨迹）
  • DNp01 阻滞   : 碰撞死亡时呈现终局去极化阻滞提示（非避障决策源）
```

| **ORN** (嗅觉受体神经元) | `ORN_DM2` | 每侧数十 | 触角刚毛 → DM2 嗅小球 | **果香酯类互补**：补充成熟果实广谱气味感知。 |
| **PN** (触角叶投射神经元) | `DM1_lPN`<br>`VA2_adPN`<br>`DM2_lPN` | 每小球 1～3 根 | 触角叶 (AL) → 侧角 (LH) / 蘑菇体 (MB) | **先天趋向中继**：投射至侧角（LH），形成天生趋食下行力矩偏置，同时触发神经调质释放。 |

#### 触角叶感觉信号物理彻底解耦
* **绝对无视网膜角度污染**：触角叶受体严格仅接收双侧化学浓度差：
  $$\Delta c = c_L - c_R$$
  $$\text{stim}_{\text{AL}, L} = \min(6.0, \max(0, \Delta c) \times 1.5), \quad \text{stim}_{\text{AL}, R} = \min(6.0, \max(0, -\Delta c) \times 1.5)$$
* **纯化学趋化（Tropotaxis）**：双侧浓度差直接通过侧向神经传递，驱动果蝇朝气味较浓的一侧自然偏转，无需介入视觉几何角度。

#### 时序气味遥测与生物学背景（Surge & Cast 的工程选型）
* **时序气味梯度（$\Delta C_t$）的真实作用**：
  在代码实现中，$\Delta C_t = c_{\max}(t) - c_{\max}(t-1)$ 作为**时序气味趋势遥测信号（Temporal Odor Trend）**，由智能体遥测包输出至前端，在 Web UI 状态栏实时反映蛇当前是在靠近还是远离食物（即界面的 `▲ Closer (Δc: +0.42)` / `▼ Further (Δc: -0.15)` 动态指示）。
* **为什么不在 2D 网格中强行引入 Cast 横切摆动？**：
  - **自然界风洞环境**：真实果蝇在三维湍流风洞中遭遇断续不均匀的气味羽流（Intermittent Plumes）时，一旦丢失羽流信号，必须依赖大幅度的左右交叉搜索（Crosswind Cast）来重新搜寻并咬住羽流边缘；
  - **2D 紧凑网格环境**：在贪吃蛇的二维离散空间中，食物气味场是连续的扩散场。双侧触角空间差分向化性（$c_L - c_R$）结合多模态气味门控视觉追踪（LC10a 视网膜锁定），已经提供了平滑、高效且安全的最优扑食路径；
  - **避免危险的自折叠横切摆动**：强行引入 Cast 横切摆动在蛇身变长或狭窄空间中会导致蛇体频繁自折叠碰撞（Self-intersection）或甩尾撞墙。因此系统保持了空间差分趋化与敏化视觉追踪的有机协同，兼具深刻的生物物理对照与工程实效。

#### 编码器侧气味敏化门控（Odor-Gated Sensitization）数学原理
在空间接口编码器侧采用敏化公式，类比真实果蝇大脑中嗅觉激活对视觉追踪通路的动态敏化（即气味门控视觉追踪 Odor-Gated Visual Pursuit）：

$$G_{\text{visual}} = G_{\text{base}} \times \left(1.0 + \alpha \cdot \frac{c_{\max}}{c_0}\right)$$

其中：
- $G_{\text{base}} = 3.5$：无气味或洁净空气中的基础视觉追踪增益。
- $c_{\max} = \max(c_L, c_R)$：触角感受到的峰值气味浓度（按距离反比衰减模型 $c = \frac{10}{1 + 0.3 d}$）。
- $c_0 = 5.0$：特征浓度归一化参考标尺。
- $\alpha = 1.5$：敏化门控放大因子。

对 LC10a 视小叶投射神经元的电刺激仅取决于几何视网膜偏航角 $\theta_{\text{bearing}}$ 与直行死区门限：
$$\text{stim}_{\text{LC10a}, L} = \min(8.0, |\theta_{\text{bearing}}| \times G_{\text{visual}}) \quad (\text{当 } \theta_{\text{bearing}} < -\theta_{\text{deadband}})$$
$$\text{stim}_{\text{LC10a}, R} = \min(8.0, |\theta_{\text{bearing}}| \times G_{\text{visual}}) \quad (\text{当 } \theta_{\text{bearing}} > +\theta_{\text{deadband}})$$

* **直行死区阈值细化（Deadband Refinement）**：
  - **参数调整**：将直行死区 $\theta_{\text{deadband}}$ 从原先粗糙的 $0.15\text{ rad}$（约 $8.6^\circ$）精细化调校为 $0.05\text{ rad}$（约 $2.86^\circ \approx 3^\circ$）。
  - **扑食瞄准精度提升**：在旧版 $0.15$ 死区下，当食物位于 $5^\circ \sim 8^\circ$ 较小偏角时，视叶因处于死区而不响应，导致直线冲刺时经常发生“擦肩而过”的失准；细化至 $0.05$ 后，微小偏角立刻被视叶感知并纠偏，大大提升了直线扑食的精准制导能力；
  - **抗噪微震荡**：保留极窄的 $\pm 3^\circ$ 盲区，有效过滤全脑膜电位微伏级波动引起的左右交替晃动，兼顾平滑直行与锋芒瞄准。
* **远距搜索区（$c_{\max} \to 1.0$）**：视觉增益维持在基线附近（约 4.5），保持平稳大范围巡航；
* **近距捕食区（$c_{\max} \to 10.0$）**：视觉增益爆发至约 14.0（敏锐度提高 $3\sim 4$ 倍），驱动蛇果断、准确地执行剧烈向心转向，直插食物坐标。

### 四、 下行运动神经元与解码规则

#### 脑-脊髓分层控制逻辑（Supraspinal Intent vs. VNC Reflex Arc）
- **上位脑部意图（Supraspinal Motor Intent）**：在前方开阔安全时，贪吃蛇执行 `DNa02` 双侧电位差模计算出的下行转向指令（TURN_LEFT / TURN_RIGHT）或 `DNa01` 巡航推进（STRAIGHT）。该过程由 16.6 万神经元在感觉输入刺激下经 4 步 LIF 动力学自发涌现，无左右常值偏置；每步开始时通过 `brain.v.fill(0)` 复位膜电位，清空跨步残留电位；
- **下位反射层（VNC 功能类比的净空 FSM）**：系统类比昆虫胸腹神经索（VNC）的外周本底反射弧，由 `MotorDecoder` 依据局部几何净空提供双重保护：当正前方遭遇贴身致命障碍（`dist_front == 0`）时触发毫秒级避碰覆写（Reflex Override，并在 HUD 仪表盘点亮 `⚡ REFLEX OVERRIDE (SPINAL COLLISION GUARD)` 警告）；当侧面贴壁（`dist_left == 0` 或 `dist_right == 0`）时，拦截向障碍侧转向的意图，保障侧向安全。这种“上位意图 + 外周保命”的双层解耦，契合昆虫运动生理学的经典分工范式。

### 五、 进食奖赏与终局保护机制

1. **PAM 多巴胺能奖励点亮**：仅在单次进食成功的瞬态窗口（`ate_food == True`）激活并受控衰减 35 帧（约 0.6 秒），以明亮琥珀金色呈现神经烟花效果；
2. **死亡状态完备保持**：碰撞死亡后模拟器立即自动锁定暂停，永久保留 2D 画布碰撞现场覆盖层、3D 巨纤维阻滞提示与遥测数据，消除自动重启造成的信息丢失；
3. **细胞查询机制**：细胞集合一律通过 `brain.cells(["类型名"], side="L"|"R")` 在运行时动态查询加载（带 `*` 号数量为参考量级），与底层内存排列完全解耦。
